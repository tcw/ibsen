# Ibsen client for Python

Generated by `ibsen generate client python` from Ibsen @@IBSEN_VERSION@@, proto @@PROTO_VERSION@@.

- `@@PACKAGE@@/ibsen_pb2*.py` — the gRPC stubs and messages, generated from `ibsen.proto`. Do
  not edit.
- `@@PACKAGE@@/client.py` — a small client over them: `write`, `read` (once, or following the
  log), `list`, and safe retries with `producer=True`.
- `example.py` — writes two entries, reads them back and lists the topics.

## Build and run the example

Needs Python 3.9 or later, and an Ibsen server: `ibsen server` keeps the log in memory and
listens on `localhost:54321`.

```shell
python3 -m venv .venv && . .venv/bin/activate
pip install .
python example.py                 # or: python example.py host:port
```

## Use it

```python
from @@PACKAGE@@ import IbsenClient

with IbsenClient("localhost:54321", producer=True) as client:
    result = client.write("orders", [b'{"id":1}'])
    for entry in client.read("orders", 0):
        ...
```

With `producer=True` the client names itself and numbers its writes, and a write whose reply
was lost is sent again with the same number; the server stores it once and answers with the
original offsets (`result.duplicate`).

## TLS

```python
import grpc
credentials = grpc.ssl_channel_credentials(open("cert.pem", "rb").read())
client = IbsenClient(channel=grpc.secure_channel("ibsen.example.com:54321", credentials))
```

against a server started with `--certKey` and `--privateKey`.
