# Ibsen client for TypeScript

Generated by `ibsen generate client typescript` from Ibsen @@IBSEN_VERSION@@, proto
@@PROTO_VERSION@@.

- `src/ibsen.ts` — the gRPC stubs and messages, generated from `ibsen.proto` with ts-proto for
  `@grpc/grpc-js`. Do not edit.
- `src/client.ts` — a small client over them: `write`, `read` (once, or following the log),
  `list`, and safe retries with `{ producer: true }`.
- `src/example.ts` — writes two entries, reads them back and lists the topics.

## Build and run the example

Needs Node 18 or later and npm, and an Ibsen server: `ibsen server` keeps the log in memory and
listens on `localhost:54321`.

```shell
npm install
npm run build
npm run example                     # or: node dist/example.js host:port
```

## Use it

```typescript
import { IbsenClient } from "@@PACKAGE@@";

const client = new IbsenClient("localhost:54321", { producer: true });
const result = await client.write("orders", [Buffer.from('{"id":1}')]);
const entries = await client.read("orders", 0);
```

With `producer: true` the client names itself and numbers its writes, and a write whose reply
was lost is sent again with the same number; the server stores it once and answers with the
original offsets (`result.duplicate`).

## TLS

```typescript
import { credentials } from "@grpc/grpc-js";
import { readFileSync } from "fs";
const client = new IbsenClient("ibsen.example.com:54321", {
  credentials: credentials.createSsl(readFileSync("cert.pem")),
});
```

against a server started with `--certKey` and `--privateKey`.
