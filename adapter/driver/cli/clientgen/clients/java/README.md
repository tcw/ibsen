# Ibsen client for Java

Generated by `ibsen generate client java` from Ibsen @@IBSEN_VERSION@@, proto @@PROTO_VERSION@@.

- `src/main/java/github/com/tcw/ibsen/client/` — the gRPC stubs and messages, generated from
  `ibsen.proto`. Do not edit.
- `src/main/java/@@PACKAGE_PATH@@/IbsenClient.java` — a small client over them: `write`,
  `read` (once, or following the log), `list`, and safe retries with `withProducer()`.
- `src/main/java/@@PACKAGE_PATH@@/Example.java` — writes two entries, reads them back and lists
  the topics.

## Build and run the example

Needs Java 17 and Maven, and an Ibsen server: `ibsen server` keeps the log in memory and
listens on `localhost:54321`.

```shell
mvn -q compile
mvn -q exec:java                                  # or: mvn -q exec:java -Dexec.args=host:port
```

## Use it

```java
try (IbsenClient client = IbsenClient.plaintext("localhost:54321").withProducer()) {
    IbsenClient.WriteResult result = client.write("orders", List.of(bytes));
    client.read("orders", 0, true, false, entry -> handle(entry));
}
```

With `withProducer()` the client names itself and numbers its writes, and a write whose reply
was lost is sent again with the same number; the server stores it once and answers with the
original offsets (`result.duplicate()`).

## TLS

Build the channel yourself and hand it over:

```java
ManagedChannel channel = NettyChannelBuilder.forTarget("ibsen.example.com:54321")
        .sslContext(GrpcSslContexts.forClient().trustManager(new File("cert.pem")).build())
        .build();
IbsenClient client = new IbsenClient(channel);
```

(`io.grpc.netty.shaded.io.grpc.netty`), against a server started with `--certKey` and
`--privateKey`.
