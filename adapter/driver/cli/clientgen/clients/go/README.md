# Ibsen client for Go

Generated by `ibsen generate client go` from Ibsen @@IBSEN_VERSION@@, proto @@PROTO_VERSION@@.

- `ibsenpb/` — the gRPC stubs and messages, generated from `ibsen.proto`. Do not edit.
- `ibsen/` — a small client over them: `Write`, `Read` (once, or following the log), `List`,
  and safe retries with `WithProducer()`.
- `example/` — writes two entries, reads them back and lists the topics.

## Build and run the example

Needs Go 1.25 or later, and an Ibsen server: `ibsen server` keeps the log in memory and
listens on `localhost:54321`.

```shell
go mod tidy
go run ./example                 # or: go run ./example host:port
```

## Use it

```go
client, err := ibsen.Dial("localhost:54321", []ibsen.Option{ibsen.WithProducer()})
result, err := client.Write(ctx, "orders", [][]byte{[]byte(`{"id":1}`)})
err = client.Read(ctx, "orders", 0, true, false, func(e ibsen.Entry) error { ...; return nil })
```

With `WithProducer()` the client names itself and numbers its writes, and a write whose reply
was lost is sent again with the same number; the server stores it once and answers with the
original offsets (`result.Duplicate`).

## TLS

Pass credentials as dial options:

```go
creds, err := credentials.NewClientTLSFromFile("cert.pem", "")
client, err := ibsen.Dial("ibsen.example.com:54321", nil, grpc.WithTransportCredentials(creds))
```

(`google.golang.org/grpc/credentials`), against a server started with `--certKey` and
`--privateKey`.
